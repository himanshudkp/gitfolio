# Portfolio Website

A modern, responsive personal portfolio website built with **React, Vite, and Tailwind CSS**.

🔗 **Live:** https://gitfolio-smoky.vercel.app/

## ✨ Features

- Responsive and mobile-friendly design
- Dark / light theme with saved preference
- Scroll-spy navigation
- Projects showcase with tech stacks and links
- Skills, experience, education, and certifications
- Resume download
- Social links
- Contact form with Web3Forms
- Smooth scroll animations

## 🛠️ Tech Stack

- React
- JavaScript
- Vite
- Tailwind CSS
- Iconify
- Web3Forms
- Vercel

## 🚀 Getting Started

### Install

```bash
git clone https://github.com/himanshudkp/portfolio-website.git
cd portfolio-website
pnpm install
```

### Run locally

```bash
pnpm dev
```

### Build

```bash
pnpm build
```

## ⚙️ Configuration

Update your personal information in:

```text
src/data/data.js
```

This includes your profile, projects, skills, experience, education, and social links.

For the contact form, add your Web3Forms access key in:

```text
src/components/Contact.jsx
```
